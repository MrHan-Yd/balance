## 2. 项目初始化


## 4. 数据与接口契约

### 4.1 状态模型（对齐设计文档 §4.1）

```dart
class CartItem {
  final String label;      // 原始识别文本片段；纯数字时为空
  final double amount;     // 金额（元），两位小数精度
  final DateTime addedAt;
}

class SessionState {
  final List<CartItem> items;      // 上限 200 条，超出归档入历史
  final List<CartItem> undoStack;  // 撤销栈
  double get total;                // = Σ amount
}
```

### 4.2 Provider 清单

| Provider | 类型 | 职责 |
| :--- | :--- | :--- |
| `sessionProvider` | `NotifierProvider<SessionController, SessionState>` | 累加/撤销/清空/归档；变更后写 hive |
| `speechProvider` | `Provider<SpeechService>` | 封装 speech_to_text：权限、识别生命周期、错误回调 |
| `historyProvider` | `NotifierProvider<HistoryController, HistoryState>` | 按天分组、删除单日、30 天自动清理 |

> 禁止在 Widget 里直接 `setState` 管理会话数据；解析器输出 → `sessionProvider` 是唯一累加入口。

### 4.3 解析器接口（对齐设计文档 §4.2）

```dart
class PriceMatch {
  final double value;
  final String rawText;   // 原文片段 → 明细 label
}

List<PriceMatch> parseVoiceTexts(String input);
// 管线: 中文数字归一化 → 金额单位映射 → 全量扫描 → 过滤（单位相邻/孤立数字/范围 0<v≤99999）
```

### 4.4 hive 存储结构

| box | key | 值 | 说明 |
| :--- | :--- | :--- | :--- |
| `session` | `items` | `List<CartItem>` | 当前会话，重启恢复（US-011） |
| `history` | `YYYY-MM-DD` | `List<CartItem>` | 每日历史；App 启动时清理 >30 天的 key |

## 5. 开发规范

1. **格式化**：`dart format .`；**静态检查**：`flutter analyze`，保持 0 warning。
2. **注释语言**：与现有文档一致使用中文，公共 API 必须写用途注释。
3. **解析器纯 Dart**：`core/parser/` 不允许 import Flutter 库，保证 `flutter test` 秒级跑完。
4. **金额计算**：全程 `double` + 两位小数显示；金额比较用 `(x * 100).round()` 避免浮点误差。
5. **权限**：iOS 双权限 + Android 运行时权限统一在 `SpeechService` 内申请，UI 只消费状态（拒绝 → keypad 模式）。

## 7. 真机调试要点

- **语音识别仅真机可用**：iOS 模拟器直接报 `notFound`；Android 建议 API 31+ 真机。
- **iOS 首次授权是两个权限**：麦克风 + 语音识别，拒绝任意一个即走 keypad 降级（US-010）。
- **Android 11+ 包可见性**：`AndroidManifest.xml` 已含 `<queries>`（设计文档 §5.2），删除会导致部分机型识别返回空。
- **假数据注入（调试用）**：`kDebugMode` 下长按语音键 3 次，弹出调试面板直接调用 `parseVoiceTexts('黄瓜5块，牛肉38')` 并注入 `sessionProvider`，便于无麦环境联调 UI。
