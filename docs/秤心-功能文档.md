---

## 1. 功能范围

**核心闭环**：说话 → 本地语音识别 → 解析金额 → 累加总价 → 明细列表 → 撤销/清空 → 历史记录。

**范围外（明确不做）**：云端同步、多设备、会员/付费、广告、单位换算（斤两→价格）、单价×重量计算、历史导出分享。

---

## 2. 用户故事与验收标准

优先级：**P0** = Phase 1-2（MVP 闭环）｜**P1** = Phase 3（完善）｜**P2** = Phase 4+（迭代）

### 2.1 语音累加（P0）

**US-001 单句识别累加**
> 作为用户，我想点击说话按钮说一句"黄瓜五块五"，让 App 识别并累加金额。
- [ ] 点击按钮后进入识别态（红色 + 脉冲动画），识别出首个有效金额后自动停止
- [ ] 识别成功：明细插入"黄瓜 ¥5.50"，总价 +5.50，轻微震动
- [ ] 3 秒无有效结果：自动停止，提示"没听清，请重说"，**不累加**

**US-002 持续识别累加**
> 作为用户，我想按住按钮连续报多个价（"五块五…三块…38"），松手一次加完。
- [ ] 按住 ≥ 300ms 进入持续识别态，按住期间每识别一个金额立即插入一条明细
- [ ] 松手停止；按住 < 300ms 视为单击（单句识别）
- [ ] 持续识别 8 秒无结果自动停止并提示

**US-003 单句多金额**
> 作为用户，我想说"黄瓜5块，牛肉38"一次加两笔。
- [ ] 解析器返回多个金额，逐条插入明细并分别累加（对应设计文档 §4.2）

**US-004 识别失败兜底**
> 作为用户，我想在嘈杂环境下说错/没听清时不被误记账。
- [ ] 识别失败或解析为空：重震动 + 提示，不产生任何累加
- [ ] 连续失败 2 次：引导切换手动键盘模式
- [ ] 识别中进入后台：立即停止识别，防止误触发

### 2.2 总价与明细（P0）

**US-005 实时总价**
- [ ] 总价卡片始终显示 Σ明细，格式 `¥1,234.56`（千分位 + 两位小数）
- [ ] 每次累加有数字滚动动画（60fps 不掉帧）
- [ ] 金额上限 99999，超限拒绝累加并提示

**US-006 明细展示**
- [ ] 每条明细显示：名称/原文片段 + 金额 + 时间，最新在底部
- [ ] 空状态显示引导文案"开始说话，自动记账"

**US-007 删除单项**
- [ ] 明细行可滑动/点击删除，删除有滑出动画，总价联动更新

### 2.3 撤销与清空（P1）

**US-008 撤销上一笔**
- [ ] 顶栏"撤销上一笔"：弹回撤销栈，撤销最近一次累加，可连续撤销
- [ ] 无历史可撤时按钮置灰

**US-009 清空全部**
- [ ] 清空需二次确认弹层（展示当前件数与总额）
- [ ] 确认后明细、撤销栈同步清空，总价归零

### 2.4 手动键盘（P1）

**US-010 键盘降级模式**
> 作为权限被拒/噪音环境下的用户，我想用数字键盘手动输入金额。
- [ ] 麦克风或语音识别权限被拒后，语音键切换为数字小键盘（0-9/./退格/确认/取消）
- [ ] 键盘输入校验：最多两位小数、单小数点、≤ 99999，非法输入不响应
- [ ] 键盘累加同样走会话状态机（可撤销、可删除），切换回语音模式不清空明细

### 2.5 会话与历史（P2）

**US-011 会话恢复**
- [ ] App 重启后自动恢复上次未清空的会话（明细 + 总价）

**US-012 历史记录**
- [ ] 历史页按天分组：日期、件数、总额，可查看明细
- [ ] 可删除单日历史
- [ ] 历史保留最近 30 天，超出自动清理；明细超 200 条时最旧条目自动归档入历史

### 2.6 反馈与无障碍（P1/P2）

**US-013 触觉/声音反馈**
- [ ] 识别成功：轻震动（lightImpact）；识别失败：重震动（heavyImpact）
- [ ] 声音反馈默认关闭（菜市场环境），设置项可开启

**US-014 无障碍**
- [ ] VoiceOver / TalkBack：每次累加播报金额，按钮有语义标签
- [ ] 支持系统字体缩放至 200% 不破版

## 3. 非功能需求

| 类别 | 需求 | 验证方式 |
| :--- | :--- | :--- |
| 性能 | 冷启动到可说话 < 1s | 真机计时（Phase 1 验收） |
| 性能 | 数字动画在 120Hz 设备 ≥ 60fps | 真机 Profiler |
| 性能 | 200 条明细滚动不卡顿 | 真机体验 |
| 电池 | 单句识别 3s / 持续识别 8s 自动停止；后台立即停止识别 | 代码审查 |
| 离线 | 零后端，全功能离线可用；App 不申请网络权限 | 清单核对 AndroidManifest/Info.plist |
| 隐私 | 语音数据仅在设备本地处理，不上传 | 代码审查 + 权限清单 |
| 存储 | 会话 + 30 天历史总数据 < 5MB | 真机实测 |
| 兼容 | iOS 15+ / Android 8.0 (API 26)+；深色模式至少不破版 | 真机矩阵 |
| 无障碍 | 满足 US-014 | 真机 VoiceOver/TalkBack 走查 |

## 5. 验收口径（全局）

1. 解析器单元测试 ≥ 40 例全绿，识别用例通过率 ≥ 95%（测试清单见设计文档 §7）
2. 真机验证清单逐项通过：iOS 18 + Android 8.0 低端机各 1 台
3. 所有 P0 用户故事验收项勾选完成，方可进入 Phase 2 后的里程碑验收
