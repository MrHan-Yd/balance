## 1. 方案概览

```text
Mac 构建未签名包 ──► 导入 iPhone ──► SideStore 首次安装（7 天有效）
                                        │
                              WireGuard 本地环路（127.0.0.1）
                                        │
                          快捷指令自动化：每周一/四 03:00 自动刷新
                                        ▼
                          有效期保持 6~7 天，零电脑依赖
```

**核心链路**：SideStore 通过 WireGuard 连接本机 loopback 网卡，实现**设备自身**续签（不需要重新连电脑）——这是免签长期使用成立的前提。

## 2. 前置条件

| 项 | 说明 |
| :--- | :--- |
| Mac（构建机） | 安装 Flutter + Xcode；`flutter doctor` 全绿 |
| iPhone | iOS 15+，设置中已登录免费 Apple ID |
| Windows（可选） | 备选方案 Sideloadly 使用（见 §7） |
| 电脑与手机 | 同一 Wi-Fi 或 USB 连接（首次安装必需） |

## 3. 构建未签名包

```bash
# 方案 A（推荐）：产出未签名 ipa，由 SideStore 直接安装
flutter build ipa --release --no-codesign

# 方案 B：产出 Runner.app，用 Sideloadly（Windows/Mac）签名安装
flutter build ios --release --no-codesign
# 产物: build/ios/iphoneos/Runner.app
```

> 注意：免费 Apple ID 签名有 **7 天有效期**，且同一账号在设备上同时最多签 3 个应用（SideStore + 本应用通常占 2 个）。

## 4. 首次安装

1. **电脑安装 SideStore**：从官网下载安装器（Windows/Mac），连接 iPhone 后安装 SideStore 到手机（电脑端只需此一次）。
2. **iPhone 信任证书**：设置 → 通用 → VPN 与设备管理 → 信任 SideStore 开发者证书。
3. **安装秤心**：
   - 方案 A：将未签名 ipa 导入 iPhone 文件 App → SideStore 中"从文件安装"。
   - 方案 B：Sideloadly 选择 `Runner.app`/ipa + 免费 Apple ID → 安装。
4. **配置 WireGuard**（SideStore 自动续签依赖）：
   - 从 SideStore 导出/获取 `SideStore.conf` 配置文件
   - 手机安装 WireGuard App → 导入该配置（端点 `127.0.0.1`）
   - 连接一次验证：SideStore 显示"已连接/在线"状态

## 5. 快捷指令自动化（每周自动续签）

1. **快捷指令 App** → 自动化 → 新建个人自动化 → 时间：每周一、周四 03:00。
2. 添加操作（按实际可用操作调整）：
   - 开启 WireGuard VPN（选择 SideStore 配置）
   - 触发 SideStore 刷新（SideStore 提供 URL scheme / 自动化支持，见其文档；也可用"打开 App"触发）
   - 等待数秒 → 关闭 WireGuard VPN
3. 关闭"运行前询问"，开启"**立即运行**"（锁屏/后台执行需在快捷指令权限中授权）。
4. **验证**：手动运行一次该自动化，确认 SideStore 中应用剩余有效期被刷新到 6-7 天。

## 6. 每周运维检查清单

- [ ] 周一/周四 03:00 后，检查 SideStore 应用剩余有效期 ≥ 6 天
- [ ] 秤心可正常打开、无闪退
- [ ] WireGuard 配置未丢失（重装/还原手机后需重配）
- [ ] 新构建版本通过同一流程更新安装（SideStore"刷新"即可覆盖安装新包）

## 7. 故障排查表

| 症状 | 可能原因 | 处理 |
| :--- | :--- | :--- |
| 应用闪退/打不开 | 证书过期且未刷新 | 打开 SideStore → 刷新所有应用；或走 §5 自动化 |
| 自动化没触发 | 快捷指令"立即运行"权限被拒 / 锁屏策略 | 重新授权；退化为每周手动刷新（SideStore 内一键） |
| SideStore 显示离线 | WireGuard 未连接 | 手动开启 WireGuard 连接 loopback |
| 识别一直失败 | 误装成模拟器包 / 权限被拒 | 重装真机包；检查麦克风+语音识别双权限 |
| iOS 大版本升级后失效 | SideStore 兼容性问题 | 关注官方更新；临时用电脑重签（§4 步骤 1-3） |
| 账号被吊销/签名失败 | 免费账号异常 | 换一个免费 Apple ID 重新签名安装 |

## 8. 备选方案

| 方案 | 场景 | 代价 |
| :--- | :--- | :--- |
| **Sideloadly**（Windows/Mac） | 无 Mac 构建环境时接收 ipa | 每次续签需连电脑，无自动化 |
| **AltStore** | 类似 SideStore，但需电脑作"服务器" | 手机脱离电脑网络无法续签 |
| **Apple Developer 账号**（$99/年） | 放弃免签，正式分发 | 年费 + 审核流程 |

> 决策建议：日常开发验证用方案 A（SideStore）；若自动化连续 2 周不稳定，退级到 §7 手动刷新（2 分钟/周），仍满足"零电脑依赖"的核心诉求。

## 9. 版本与产物管理

- 版本号：`pubspec.yaml` 的 `version` 字段，语义化版本（如 `1.0.0+1`）。
- 产物归档：每期发布将未签名 ipa 存至 `build/release/` 并记录 SHA256，便于回溯。
- 更新渠道：无应用商店，通过 SideStore 覆盖安装（见 §6 检查清单）。
